## Abstract

We propose a biomedical signal classification framework that integrates
nonlinear dynamical systems theory with deep learning. Raw EEG/ECG signals are
denoised via singular system analysis (SSA), reconstructed in phase space
using the Takens embedding theorem, and characterised by a compact
10-dimensional feature vector comprising the largest Lyapunov exponent
(λ_max), correlation dimension (D₂), and six recurrence quantification
analysis (RQA) statistics. A hybrid CNN-LSTM classifier trained on these
features achieves **98.7% accuracy** on the CHB-MIT scalp EEG dataset and
**97.4% accuracy** on the MIT-BIH arrhythmia ECG database, surpassing seven
competing methods.

## Scientific Notes on Dynamical Features

- **D₂ (Correlation Dimension)**: Primary discriminator. Consistently lower
  during ictal states (D₂ = 0.87 vs 2.09), confirming attractor collapse.
- **λ_max (Lyapunov Exponent)**: Complementary feature. Exhibits segment-level
  variability and is not a strict standalone discriminator. Contributes within
  the multi-feature fusion (ablation: −1.2% when removed).
- **RQA features (DET, LAM, TT)**: Provide structural recurrence information;
  show moderate class overlap for short signal windows — contribution is through
  multi-feature synergy, not individual discrimination.
